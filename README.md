# Epic Events CRM

## Installation
```bash
uv pip install -e .
```

## Commandes disponibles

### Authentification
```bash
epicevent login
epicevent logout
```

### Collaborateurs
```bash
epicevent collaborators list
epicevent collaborators add
epicevent collaborators update
epicevent collaborators delete
```

### Clients
```bash
epicevent clients list
epicevent clients add
epicevent clients update
epicevent clients delete
```

### Contrats
```bash
epicevent contracts list
epicevent contracts add
epicevent contracts update
epicevent contracts sign
epicevent contracts delete
```

### Événements
```bash
epicevent events list
epicevent events add
epicevent events update
epicevent events assign
```
